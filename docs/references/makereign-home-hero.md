# MakeReign Home Hero Reference

## 기본 정보

- Site ID: makereign-home-hero
- 원본 URL: https://www.makereign.com/
- 적용 대상: `/`의 `ExecutiveSummary`
- 현재 완료 단계: R5
- 조사일: 2026-07-30

## 런타임 구조

- Nuxt 기반 `HomeHero` 컴포넌트다.
- 전체 부모 높이는 `225vh`, 내부 장면은 `sticky top: 0`이다.
- 첫 `100%` 스크롤 구간에 scrub 타임라인을 사용한다.
- 풀스크린 장면은 최종적으로 viewport 대비 약 `180px × 100px` 비율까지 축소된다.
- 기준 1728px viewport에서 장면은 `x: -305px`, `y: 50vh - 273px`로 이동한다.
- 라운드 마스크 값은 스크롤 진행률과 함께 증가한다.
- 흰색 타이틀은 중간 구간에서 사라지고 검은색 타이틀이 등장한다.
- 헤드라인의 일부 단어는 `x: 182%`, `x: 370%`에서 각각 `0%`, `70%`로 이동한다.
- 포인터 좌표에 따라 최대 약 45도의 rotateX/rotateY가 적용되며 진행률 중앙에서 가장 강하다.
- 진입 시 장면은 아래에서 올라오며 `clip-path`와 둥근 모서리가 해제된다.

## NEXT 적용

- 하나의 영상 대신 여러 금융 비주얼을 묶은 레이어를 사용한다.
- 분산 레이어 전체를 스크롤에 따라 축소하고 좌측 하단 방향으로 이동한다.
- `Media-First Pipeline` 메시지는 축소가 진행되는 중후반에 등장한다.
- 포인터 3D 반응은 과도한 기울기를 피하고 금융 랜딩에 맞게 제한한다.

## 미확인

- 동일 viewport 실제 프레임 캡처
- 장면 내부 HomeSlides의 개별 전환 타임라인
- 모바일은 별도 `HomeHeroMobile`이므로 데스크톱 전환을 그대로 사용하지 않는다.

공개 SSR과 `/_nuxt/facdb79.js`의 런타임 분석 및 로컬 구현은 R5 단계다.
동일 viewport 프레임 비교가 완료되기 전까지 R7로 보고하지 않는다.
## 2026-07-30 구현 기록

- 로컬 `ExecutiveSummary`를 225vh 부모와 100svh sticky 화면으로 구성했다.
- 7개 로컬 이미지는 중앙 수평 트랙으로 배치하고, 스크롤 중 30도 회전·1.3배 확대·홀짝 수직 이동을 적용했다.
- 첫 100vh 동안 전체 장면이 1728px 기준 180×100 비율의 타일로 수축한다.
- 진행률 80~90%에서 이미지 트랙과 로컬 영상 `executive-summary-play.mp4`가 교차 전환된다.
- 최종 타일 호버 시 캡슐 마스크, 영상 확대, 양쪽에서 들어오는 라벨을 적용했다.
- 프로덕션 빌드는 통과했다. 브라우저 세션을 사용할 수 없어 동일 뷰포트 프레임 비교와 실제 포인터 검증은 보류했다.
- 현재 단계: R5. 모든 실행 에셋은 로컬이며 원격 미디어/API/프록시 의존성은 없다.

## 2026-07-31 타이틀 결합 모션

- 공개 `HomeHero` 런타임의 첫 100% scrub 구간을 다시 확인했다.
- 원본은 분리된 헤드라인 단어를 `x: 182%`, `x: 370%`에서 시작해 각각
  `0%`, `70%`로 이동시키며 `power2.out` easing을 사용한다.
- 로컬은 Executive Summary 진행률 0–62%를 별도 타이틀 진행률로 매핑하고,
  `1 - (1 - progress)²` easing을 적용했다.
- `Media-Pipeline`은 좌측 기준점에 고정하고 `First Trading`만 데스크톱에서
  `-52vw`, 태블릿·모바일에서 `-29vw` 이동해 왼쪽 문구에 결합한다.
- 역방향 스크롤은 동일 진행률 계산으로 원래의 좌우 분리 상태를 복원한다.
- `prefers-reduced-motion`에서는 텍스트 이동을 비활성화한다.

## 2026-07-31 세 프레임 타임라인 재구성

- 사용자 제공 프레임의 순서를 우선해 장면을 세 구간으로 분리했다.
- 0–62%: 분산된 7개 금융 이미지가 `power2.out` 곡선으로 최종 타이틀 슬롯까지
  축소·이동한다. 이 구간에는 초기 분리 텍스트를 표시하지 않는다.
- 62–68%: 작은 장면을 슬롯 위치에 잠시 유지해 두 번째 프레임을 만든다.
- 68–100%: 최종 타이포그래피가 나타나며 `First`와 `Trading`만 화면 오른쪽에서
  왼쪽 최종 위치로 이동한다. 설명 문단은 타이틀 이동 후반에 등장한다.
- 첫 프레임의 초록색 아래 화살표 버튼은 축소가 시작되면서 사라지고, 클릭 시
  해당 sticky 타임라인을 앞으로 진행한다.
- 타임라인은 스크롤 위치에서 매 프레임 재계산하므로 역방향으로도 동일하게
  세 상태가 복원된다.

## Capability rows / Core Strengths

- `ExecutiveSummary` 다음에 3개의 대형 capability row를 배치했다.
- 행 전체를 포인터 진입 영역으로 사용하고 활성 행의 preview 이미지를 opacity/scale로 교체한다.
- 원본 `HomeCasesItem`은 미디어에 스크롤 패럴랙스(`y: -15% → 15%`, `scale: 1.1`)를 사용하며, 호버의 핵심은 `data-cursor="plus"` 커스텀 커서다.
- 로컬 구현도 행마다 고정 버튼을 두지 않고 리스트 위를 따라오는 하나의 초록색 플러스 커서를 사용한다.
- Core Strengths는 3열 카드 중 활성 카드만 밝은 배경과 원색 이미지로 부각한다.
- 현재 제공된 별도 카드 사진이 없어 기존 로컬 summary/content 이미지를 사용한다. 외부 이미지 의존성은 없다.

## 2026-08-03 Capability hover 프리뷰

- 사용자 제공 MakeReign 프레임을 이 인터랙션의 R1 기준 화면으로 삼았다.
- 행에 포인터가 진입하면 클릭 없이 즉시 배경이 어두워지고, 초록색 플러스 커서와
  세로형 프리뷰가 동시에 나타난다.
- 프리뷰는 커서 오른쪽 84px에 배치하고 세로 중심을 커서와 맞춘다. 좌표는 매 프레임
  0.12 감쇠 보간하며, 최대 5도 이내의 미세한 회전과 2% 내부 이미지 패럴랙스만 적용한다.
- 프리뷰는 중앙 `clip-path: inset(50%)`에서 0으로 0.55초 동안 열리고, 영역 이탈 시
  역방향으로 닫힌다.
- 스크롤로 행이 정지한 커서 아래에 들어오는 경우 브라우저가 `pointerenter`를 다시
  발생시키지 않을 수 있다. 전역 포인터 좌표와 `elementFromPoint()`를 스크롤 프레임마다
  대조해 클릭 없이 활성 행을 갱신하도록 보완했다.
- 현재 단계는 R5다. 프리뷰 이미지와 실행 코드는 로컬이며 원격 런타임·미디어·API·프록시
  의존성은 없다. 사용자 제공 기준 프레임과 FHD 포인터 진입/스크롤 역방향을 로컬에서 검증한다.

## 2026-08-03 First / Trading 속도 재검증

- 현재 공개 HTML이 로드하는 `/_nuxt/facdb79.js`의 `HomeHero.setScroll()`을 다시 확인했다.
- 원본 단어 이동의 ScrollTrigger는 `start: "top top"`, `end: "+=100%"`,
  `scrub: true`이며, 이동 tween의 easing은 `power2.out`이다.
- 첫 번째 이동 단어는 `x: 182% → 0%`, 두 번째 이동 단어는
  `x: 370% → 70%`로 첫 100vh 스크롤 전체에 걸쳐 이동한다.
- 원본과 같은 225vh 부모에서 실제 sticky 스크롤 가능 거리는 125vh이므로,
  로컬 정규화 진행률에서는 `0 → 0.8` 구간이 원본의 `+=100%`에 해당한다.
- 기존 로컬 구현은 `0.7 → 1.0`의 마지막 30%에 이동을 압축해 원본보다 약 2.67배
  짧은 구간에서 움직였다. 이를 `0 → 0.8`로 확장하고 동일한
  `1 - (1 - p)²` (`power2.out`) 곡선을 적용한다.
- 현재 단계는 R5다. 로컬 모션은 편집 가능한 소스이며 외부 런타임·미디어·폰트·API·프록시
  의존성은 0개다. 동일 viewport의 자동 프레임 비교 환경이 없어 R7 검증은 보류한다.

## 2026-08-03 보조 카피 글자 리빌

- 현재 공개 HTML이 참조하는 `/_nuxt/facdb79.js`의 `FragmentsTitle`을 확인했다.
- 원본은 SplitText로 문장을 line/word/char 단위로 분리하고 각 줄을
  `overflow: hidden` 마스크로 감싼다.
- 각 글자는 `yPercent: 105`에서 시작해 `yPercent: 0`으로 올라온다. 개별 글자
  duration은 0.6초, 글자 stagger는 0.03초, 줄 stagger는 0.1초이며 easing은
  `power2.out`이다.
- 로컬 `From Insight / to Instant Trade`를 SVG 한 장에서 편집 가능한 실제 텍스트로
  교체했다. 두 줄을 각각 마스크하고 동일한 105% 이동량, 0.6/0.03/0.1 타이밍 비율,
  `1 - (1 - p)^2` 곡선을 적용했다.
- 이 문장은 `Media-First / Pipeline Trading` 결합 모션이 100% 완료되는 전체 진행률
  80% 지점 이후에도 마스크 아래에 유지한다. 완성된 타이틀을 80–86% 구간에서
  홀드한 뒤, 남은 86–100% 구간에 scrub 방식으로 연결된다.
  빠른 스크롤과 역방향 스크롤에서도 현재 진행률로 모든 글자 위치를 재계산한다.
- 우측에 별도로 노출되던 한국어 설명 문단은 제거해 타이포그래피 시퀀스만 남겼다.
- `prefers-reduced-motion`에서는 글자 이동 없이 완성된 문장을 표시한다.
- 현재 단계는 R5다. 실행 코드와 미디어는 로컬이며 원격 API·프록시 의존성은 없다.
  전역 Ubuntu 설정에 사용자가 요청한 Google Fonts 스타일시트 의존성 1개가 남아 있다.
  동일 viewport 자동 프레임 비교 환경이 없어 R7 검증은 보류한다.
