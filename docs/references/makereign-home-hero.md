# MakeReign Home Hero Reference

## 기본 정보

- Site ID: makereign-home-hero
- 원본 URL: https://www.makereign.com/
- 적용 대상: `/`의 `ExecutiveSummary`
- 현재 완료 단계: R0
- 조사일: 2026-07-30

## 런타임 구조

- Nuxt 기반 `HomeHero` 컴포넌트다.
- 전체 부모 높이는 `225vh`, 내부 장면은 `sticky top: 0`이다.
- 첫 `100%` 스크롤 구간에 scrub 타임라인을 사용한다.
- 풀스크린 장면은 최종적으로 viewport 대비 약 `180px × 100px` 비율까지 축소된다.
- 기준 1728px viewport에서 장면은 `x: -305px`, `y: 50vh - 273px`로 이동한다.
- 라운드 마스크 값은 스크롤 진행률과 함께 증가한다.
- 흰색 타이틀은 중간 구간에서 사라지고 검은색 타이틀이 등장한다.
- 헤드라인의 일부 단어는 `x: 182%`, `x: 370%`에서 각각 `0%`, `70%`로 이동한다.
- 포인터 좌표에 따라 최대 약 45도의 rotateX/rotateY가 적용되며 진행률 중앙에서 가장 강하다.
- 진입 시 장면은 아래에서 올라오며 `clip-path`와 둥근 모서리가 해제된다.

## NEXT 적용

- 하나의 영상 대신 여러 금융 비주얼을 묶은 레이어를 사용한다.
- 분산 레이어 전체를 스크롤에 따라 축소하고 좌측 하단 방향으로 이동한다.
- `Media-First Pipeline` 메시지는 축소가 진행되는 중후반에 등장한다.
- 포인터 3D 반응은 과도한 기울기를 피하고 금융 랜딩에 맞게 제한한다.

## 미확인

- 동일 viewport 실제 프레임 캡처
- 장면 내부 HomeSlides의 개별 전환 타임라인
- 모바일은 별도 `HomeHeroMobile`이므로 데스크톱 전환을 그대로 사용하지 않는다.

현재는 공개 SSR과 `/_nuxt/facdb79.js`의 `HomeHero` 런타임을 분석한 R0 단계다.
## 2026-07-30 구현 기록

- 로컬 `ExecutiveSummary`를 225vh 부모와 100svh sticky 화면으로 구성했다.
- 7개 로컬 이미지는 중앙 수평 트랙으로 배치하고, 스크롤 중 30도 회전·1.3배 확대·홀짝 수직 이동을 적용했다.
- 첫 100vh 동안 전체 장면이 1728px 기준 180×100 비율의 타일로 수축한다.
- 진행률 80~90%에서 이미지 트랙과 로컬 영상 `executive-summary-play.mp4`가 교차 전환된다.
- 최종 타일 호버 시 캡슐 마스크, 영상 확대, 양쪽에서 들어오는 라벨을 적용했다.
- 프로덕션 빌드는 통과했다. 브라우저 세션을 사용할 수 없어 동일 뷰포트 프레임 비교와 실제 포인터 검증은 보류했다.
- 현재 단계: R5. 모든 실행 에셋은 로컬이며 원격 미디어/API/프록시 의존성은 없다.
